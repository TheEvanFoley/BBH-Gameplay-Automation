# Parity Checklist

## Objective

Determine whether the PC version can be trusted as a stand-in for arcade site behavior.

## Compare

1. Site layout
2. Site variants
3. Mirrored states
4. Buck spawn paths
5. Critter behavior
6. Shot timing windows
7. Scoring behavior

## Evidence Sources

- player familiarity from weekly target treks
- direct PC gameplay capture
- direct arcade recordings
- side-by-side note review

## Decision Rule

If parity is good enough to produce reliable site-prep knowledge, PC capture can accelerate analysis.

If parity is not good enough, manual arcade video review remains the primary path.
